# World3D (Expo)

1. npm install
2. npx expo install --fix
3. npx expo start   -> scan QR with the Expo Go app to test
4. npm i -g eas-cli && eas login
5. eas build:configure   (first time only)
6. eas build -p android --profile preview   -> gives you an installable APK link
   (iOS: eas build -p ios --profile preview, needs an Apple developer account)
